- STEP files: imported with a CAD kernel and each contains one solid. Bounding boxes were read from the STEP geometry.
- STL previews: generated from the available mesh exports.
- KiCad: a graphical system-level draft only. KiCad CLI/ERC was not available here, so syntax opening and ERC have not been independently confirmed. It is not a pin-accurate schematic.
- MATLAB: script source reviewed; the PNG is a recreation of its synthetic test data for convenient viewing, not a MATLAB execution log.
- SolidWorks: no native SLDPRT was generated.
- Hardware: physical wiring, board labels, power rails, and enclosure fit are unverified because only the overall photo and firmware text were available.
